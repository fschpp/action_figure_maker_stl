# Caballo de referencia

`horse_baseless.stl`: caballo estático sin base, aportado por el cliente (SHA-256 `be06ddf1d9ba9c9e09b301280470c758a29597338522eb99093ac08f4e9a8e1d`). Se usa para el plan de caballos compatibles (`PLAN_caballos_compatibles.md`).

* 64 324 triángulos, una sola cáscara, estanco. Unidades del archivo desconocidas (44 u de alto): a escala 3× mide ≈42 × 152 × 133 mm.
* Mira hacia −Y (cabeza en −Y): entra con `yaw = 180` para quedar en el marco canónico (Y hacia la cabeza). Lo carga `afm.equestrian.load_horse_mesh`.
